# Musical Billiards
This is a music sequencer I wrote for the Music 256A class at Stanford University. To run, install chuck from [chuck.stanford.edu](https://chuck.stanford.edu/) and install the required packages with 
```
chump install chodash
```

Then, run the program with
```
chuck main.ck
```

# Controls
Click one of the 12 nodes to spawn a ball and left-click another node to send it bouncing forever in that direction (clicking the same spot again instead will cancel it and despawn the ball). You can also select between different waveforms with the number keys 1-4 after spawning the ball but before sending it off, allowing for more interesting timbres. Right-clicking a node will toggle muting it, allowing you to make more complex musical patterns. Pressing "[" will mute all nodes and pressing "]" will unmute them all. Also, pressing the minus key will remove the most recent ball.
